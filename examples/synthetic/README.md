# Synthetic examples

Everything in this directory is synthetic. It demonstrates offline configuration and artifact structure only.

- [`dry-run-manifest.json`](dry-run-manifest.json) is generated by the repository's quickstart. It is **not** benchmark evidence and contains no observed latency, throughput, reliability, cache, context, or provider usage.
- [`report.json`](report.json) is a normalized report from a real run against the local mock provider in [`../local-benchmark/`](../local-benchmark/): the `smoke` profile, 2 requests, `--execute` over loopback. Both trials completed naturally with HTTP 200. No external endpoint was contacted.

Neither file is benchmark evidence about any real provider. The report's timings describe loopback mock behavior (about 1 ms here), which measures the mock rather than a model. Its `metric_validity` states are deliberately imperfect: tokenized metrics read `invalid_client_tokenization` because the mock's token accounting is an approximation, not a tokenizer, and output throughput reads `invalid_token_sizing`. That is the reporting behaving correctly for weak sizing evidence.

The report was produced by `endpoint-bench report --run <run-dir>` at result schema `0.2.0`. Absolute scratch paths in the engine-provenance block were replaced with `<run-dir>` when publishing; measurements and classifications are otherwise unmodified. The referenced `trials.jsonl` and raw AIPerf artifacts are not committed.
