# License decision

**Status:** Approved and adopted on 2026-11-01.

## Recommendation

Adopt **MIT**, using the exact text in [`LICENSE`](../LICENSE).

MIT is short, familiar, and compatible with broad open-source use. It does not add an explicit patent grant. **Apache-2.0** is the alternative if an explicit patent grant and more detailed contribution terms are preferred; it is also the license used by AIPerf.

Either choice permits depending on Apache-2.0 dependencies. Copying AIPerf source would require preserving its Apache-2.0 notices and attribution; this project should depend on AIPerf rather than vendor it.

## Current state

The owner approved MIT as part of the P0 reconciliation pass. Future license changes require a new owner decision and compatibility review.
